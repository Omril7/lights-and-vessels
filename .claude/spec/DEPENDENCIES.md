## Important Notes

- **No generic AI aesthetics.** No purple gradients, no Inter font, no cookie-cutter cards. This should look like it was designed by a human with taste for a specific artist.
- **Image-heavy design.** Product photography is the star. Give images room to breathe.
- **The admin panel can be functional/clean** — it doesn't need to be as fancy as the storefront, but it should be polished and intuitive. Use a clean sidebar layout with clear navigation.
- **Mobile-first.** Every page must work beautifully on 375px screens.
- **Seed data matters.** Use realistic product names, descriptions, and placeholder images (use picsum.photos or unsplash source URLs) so the site looks real during development.
